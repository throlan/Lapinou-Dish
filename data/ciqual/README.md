# Source de données — Ciqual 2025

Fichier `ciqual-2025.json`: représentation compacte de la table publique Anses Ciqual 2025 (3 484 aliments, 74 constituants, noms français/anglais, valeurs pour 100 g et marqueur de confiance).

Source: Anses, *Table de composition nutritionnelle des aliments Ciqual 2025*, DOI [10.57745/RDMHWY](https://doi.org/10.57745/RDMHWY). Licence Ouverte / Open Licence 2.0: [Etalab](https://www.etalab.gouv.fr/licence-ouverte-open-licence/). Attribution: “Anses. 2025. Table de composition nutritionnelle des aliments Ciqual 2025.”

Les valeurs sont des moyennes de référence, pas des mesures de marque. Les valeurs nulles du fichier restent inconnues dans le catalogue; elles ne sont jamais converties en zéro. Ciqual est chargé dans la table unique des aliments, puis modifiable par l'administrateur.

Copie issue du jeu compact utilisé par le prototype Norish Family; le code et le schéma Norish ne sont pas repris dans ce dépôt. Avant une livraison publique, conserver cette attribution et vérifier la version/source amont.
