# Session du 16 octobre 2026

## Photos de recettes persistantes et configuration OpenAI

- Le stockage des photos personnelles et illustrations peut maintenant utiliser un dossier persistant réglé par `RECIPE_IMAGE_DIR`. Le chemin retenu pour Unraid est `/images` dans le conteneur, mappé par l'utilisateur vers `/mnt/user/appdata/lapinoudish/images`.
- Les nouvelles images sont écrites dans des fichiers privés nommés de façon unique ; PostgreSQL conserve leur nom, leur type et leur source. Les anciennes images stockées en base sont déplacées au démarrage lorsque le dossier persistant est configuré. Sans dossier, le stockage PostgreSQL reste disponible.
- Compose monte un volume dédié sur `/images`. Le template Unraid et la documentation utilisent le chemin hôte exact communiqué par l'utilisateur. Le conteneur conserve l'identité `99:100`.
- La migration SQL autorise le stockage par fichier ou par octets, avec une contrainte empêchant un enregistrement sans stockage ou avec deux emplacements simultanés.
- Le template expose séparément la clé API, le modèle d'import `OPENAI_RECIPE_MODEL` et le modèle d'image `OPENAI_IMAGE_MODEL`. Une erreur `403 model_not_found` reste liée à l'accès au modèle dans le projet associé à la clé et ne se règle pas par le stockage des images.
- Vérification : suite complète de tests réussie, notamment sauvegarde/lecture/remplacement/suppression sur disque, migration des images existantes et repli PostgreSQL sans dossier configuré. Aucune vérification ni modification sur Unraid ou Nginx.
